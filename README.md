## 🛠️ Tecnologias e Conceitos Aplicados

Durante o desenvolvimento deste projeto guiado, o objetivo principal foi unir a base teórica e aplicar soluções reais de mercado focadas em performance e experiência do usuário (UI/UX):

*   **Estruturação Semântica:** Uso correto das tags do HTML5 para garantir acessibilidade e uma boa leitura do código.
*   **CSS Grid & Flexbox:** Arquitetura de layout moderna e responsiva, garantindo que o portfólio se adapte perfeitamente em dispositivos móveis (Mobile First) e desktops.
*   **Dark Mode Nativo:** Gerenciamento de temas visuais fluidos utilizando variáveis globais CSS (`:root`) integradas com lógica em JavaScript para a troca de estados.
*   **Navegação Persistente:** Implementação de cabeçalho fixo no topo da janela (`position: fixed`) com compensação precisa de rolagem através do `scroll-margin-top` para evitar sobreposição de títulos nas âncoras internas.
